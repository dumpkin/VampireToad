# GUI Модульна архітектура

Папка `GUI/` містить розділений на модулі інтерфейс системи Vampire Toad з операційною системою PENTA OS v2.0.

## Структура модулів

### 🎮 gui_core.h / gui_core.cpp
**Ядро GUI системи**
- Основна логіка меню (MAIN_MENU)
- Обробник кнопок (checkButtons)
- Керування станами екранів (MenuState)
- Навігація між усіма режимами
- Дві-, трьохетапна навігація для хакерських режимів

### 🛠️ gui_common.h / gui_common.cpp
**Спільні утиліти для всіх екранів**
- Універсальна плашка статус-бару (годинник + вольтметр батареї)
- Стандартна розмітка підменю (drawSubMenuLayout)
- Сплеш-скрін при завантаженні
- Розрахунок київського часового зміщення
- Отримання напруги батареї з кешуванням
- Хакерські іконки (Wi-Fi та Bluetooth)

### 📻 gui_radio.h / gui_radio.cpp
**Інтерфейс FM-радіоприймача**
- Відрисовка екрана радіо (drawRadioScreen)
- Обробник кнопок для радіо-режиму
- Поцифрове введення частоти (0-9 розряди)
- Керування гучністю (0-63)
- Анімація курсору при редагуванні
- Діапазон: 100-1150 кГц

### 🧭 gui_compass.h / gui_compass.cpp
**Компас та інерціальна система**
- Відрисовка компаса з шкалою напрямків
- Показ курсу, висоти, атмосферного тиску
- Швидкості (IMU та GPS)
- Динамічна шкала з позначками сторін світу (N, E, S, W)
- Інтеграція з датчиком GY91

### 📡 gui_radar.h / gui_radar.cpp
**GPS та радарна система**
- Відрисовка GPS-радара та супутників
- Показ кількості супутників у використанні
- Інтеграція з модулем ModuleGPS
- Динамічне оновлення позиції

### 📶 gui_wifi.h / gui_wifi.cpp
**Wi-Fi атаки та сканування**
- Екран сканування Wi-Fi мереж
- Трьохетапна навігація:
  - **Етап 0**: Вибір цілі (точка доступу)
  - **Етап 1**: Вибір типу атаки (Deauth/Beacon Spam)
  - **Етап 2**: Активна атака з індикатором
- Показ RSSI та SSID мереж
- Анімована іконка Wi-Fi

### 📱 gui_ble.h / gui_ble.cpp
**Bluetooth (BLE) атаки та сканування**
- Екран сканування BLE пристроїв
- Трьохетапна навігація (аналогічно Wi-Fi):
  - **Етап 0**: Вибір цілі (BLE пристрій)
  - **Етап 1**: Вибір типу атаки
  - **Етап 2**: Активне глушення з індикатором
- Показ RSSI та імен пристроїв
- Анімована іконка Bluetooth

## Глобальні змінні (GUI::)

Визначаються в `gui_core.cpp`:
```cpp
MenuState currentState;        // Поточний екран
int currentItem;               // Поточний пункт меню
int hackerSubStage;            // Етап хакерської атаки (0, 1, 2)
int selectedTargetIndex;       // Вибрана ціль
int selectedAttackType;        // Вибраний тип атаки
```

## Як підключити

Основний файл `../gui.h` автоматично включає всі модулі:

```cpp
#include "gui.h"  // Підключає всі GUI модулі
```

## Компіляція

Усі файли компілюються через PlatformIO:
```bash
pio run
```

## Примітки

- Кожен модуль незалежний та може бути модифікований окремо
- Спільні утиліти розміщені в `gui_common`
- Двоспрямовані функції експортуються через `extern`
- Весь код відповідає namespace `GUI` для уникнення конфліктів імен
