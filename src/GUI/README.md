# GUI: модульна архітектура пристрою

Код інтерфейсу рознесений у `src/GUI/` по окремих модулях. Це дає чіткий поділ між логікою меню, радіо, навігацією, сенсорами, Wi‑Fi, BLE та іншими функціями пристрою.

## Що вміє пристрій
- Основне меню та перемикання між екранами
- Режими ARK, AM та FM
- FM/AM прийом і ручне редагування частоти
- Регулювання гучності короткими кліками
- GPS-компас із картою неба супутників, Wi‑Fi, BLE, splash-екран
- Кнопочна логіка у стилі меню: короткий клік без довгих утримань
- Робота з I2C-датчиками, звуком, дисплеєм і мікроконтролером ESP32-S3

## Модулі пристрою
- `gui_core` — логіка меню, обробка кнопок, стани екранів
- `gui_common` — спільний layout, footer, батарея, splash
- `gui_radio` — радіо-UI, гучність, частота, редагування
- `gui_navigation` — об'єднаний GPS-компас і карта неба
- `gui_wifi` — Wi‑Fi сканування та атаки
- `gui_ble` — BLE сканування та атаки
- `mod_radio` — Si4735, I2C, reset, налаштування частоти
- `mod_gy91` — IMU/GY-91, MPU9250, BMP280, AK8963
- `mod_gps` — GPS (TinyGPS++)
- `mod_sound` — бузер і звукові ефекти
- `mod_cyber` — Wi‑Fi/BLE хакерські функції та робочі модулі
- `mod_test` — тести клавіатури, I2C та дисплея

### GPS-компас і показники датчиків
- У пункті меню `GPS-COMPASS` кнопки UP/DOWN циклічно перемикають skymap, курс, тиск/температуру, барометричну висоту, швидкість IMU, GPS-координати та кількість супутників.
- Skymap повертається за відфільтрованим магнітним курсом; швидкість IMU компенсує гравітацію та шум акселерометра.
- Останні GPS-координати зберігаються в NVS та показуються після втрати сигналу; час і координати беруться з TinyGPS++, а skymap супутників — з NMEA GSV.
- У Serial Monitor повні прийняті NMEA-речення виводяться з префіксом `[GPS NMEA]`.
- Назва показника виводиться найменшим шрифтом; відсутні або невалідні показники відображаються як `---`.

### Wi‑Fi модуль
- Функціонал: сканування мереж і показ SSID/RSSI/каналів; `c`/`d` змінюють вибрану мережу (`c` вниз, `d` вгору), `#` повертає в меню.
- Робочий шар: `ModuleCyber` + `gui_wifi`, використовує ESP32 Wi‑Fi API через `esp_wifi`.
- Піни: зовнішніх пінів не додає; працює через внутрішній Wi‑Fi модуль ESP32.
- Зауваження: призначений для тестів/досліджень у контролюваному середовищі.

### Bluetooth модуль
- Функціонал: сканування BLE-пристроїв і показ RSSI/імен; `c`/`d` змінюють вибраний пристрій (`c` вниз, `d` вгору), `#` повертає в меню.
- Робочий шар: `ModuleCyber` + `gui_ble`, використовує вбудований BLE стек ESP32.
- Піни: без окремих GPIO; працює через внутрішній BLE контролер ESP32.
- Зауваження: використовувати лише у законному, дозволеному середовищі.

### GY‑91 модуль
- Склад: MPU9250 (акселерометр/гіроскоп), BMP280 (барометр/температура), AK8963 (магнітометр).
- I2C: SDA = GPIO8, SCL = GPIO9.
- Адреси: MPU9250 = `0x68`, BMP280 = `0x76`, AK8963 = `0x0C`.
- Функціонал: калібрування, інерціальні дані, курс, висота, швидкість, dead reckoning.
- Зауваження: AK8963 читається через I2C bypass режим MPU9250; для коректної роботи потрібен старт шини `Wire.begin()` до читання регістрів.

## Поведінка радіо
- ARK: 100–1150 kHz
- RX-MEDIA: FM 64.00–108.00 MHz, AM 520–30000 kHz
- `c`/`d` змінюють гучність кроком 5 (0–63)
- `a` перемикає ARK ↔ AM; повторні натискання чергують ці два режими
- `b` перемикає на FM
- Натисни `*`, введи частоту цифрами та підтверди `*`; `#` скасовує введення.
- Ввід починається з поточної частоти: цифри замінюють її зліва направо, `a` повертається на попередню позицію та обнуляє її.
- ARK вводиться в кГц (наприклад `561`); FM — п’ять цифр у сотих МГц (наприклад `10150` = 101.50 МГц); AM — у кГц (наприклад `1000`).
- Аудіоаналізатор є режимом за замовчуванням: верхня частина показує форму хвилі, нижня — прокручуваний спектр у 30 відтінках синього. Клавіша `0` перемикає на RF-waterfall і назад; у режимі RF сканування звук вимкнено. Крок сканування: AM — 1 кГц, FM — 100 кГц.
- Аудіоспектр FFT вмикається/вимикається клавішею `1`; використовує GPIO3, 128 відліків на 8 кГц (до 4 кГц). Потрібен зовнішній аудіосигнал, AC-зв'язок і зміщення до середини діапазону ADC.

## Клавіатурна матриця
- `mod_buttons` обробляє nINT SX1509 через GPIO4; ISR лише ставить прапорець, сканування I²C відбувається в головному циклі. Матриця: стовпці 0–3, рядки 4–7.
- `*` — вхід/OK, `#` — вихід/BACK, `c` — вниз/DOWN, `d` — вгору/UP.
- Під час сплеш-екрана утримання `#` запускає тест усіх клавіш; натискання підсвічуються на дисплеї та фіксуються в Serial Monitor. Після тесту завантаження продовжується; якщо SX1509 не ініціалізувався, тест пропускається.
- Меню, радіо, GPS-компас і перегляд списків Wi‑Fi/BLE керуються цими клавішами; поріг утримання — 1200 мс.
- Wi‑Fi/BLE екрани показують результати сканування; кнопка OK не запускає передачу пакетів чи глушіння.

## I2C пристрої та адреси
- SX1509 expander: `0x3E`
- MPU9250: `0x68`
- BMP280: `0x76`
- AK8963: `0x0C`
- Si4735: адреса залежить від плати/підключення та перевіряється через `getDeviceI2CAddress()`

## Pinout (кодування в проекті)
- TFT (SPI): MOSI = GPIO11, SCLK = GPIO12, CS = GPIO15, DC = GPIO16, RST = GPIO14
- GY-91 (I2C): SDA = GPIO8, SCL = GPIO9
- SX1509 expander: I2C address `0x3E`
  - nINT: GPIO4
  - стовпці матриці: піни 0–3
  - рядки матриці: піни 4–7
  - `*` = OK, `#` = BACK, `c` = DOWN, `d` = UP
- Radio reset: GPIO10 (пін SX1509 0 зайнятий матрицею)
- Buzzer: `BUZZER_PIN = 2` (ledc channel 0)
- Pot / battery ADC: GPIO1
- Audio analyzer ADC input: GPIO3 (ADC1); connect only an AC-coupled, biased audio signal within 0–3.3 V.

## Примітки
- Клавіатурна матриця сканується через піни SX1509; прямі GPIO ESP32 для клавіш не використовуються.
- Reset радіо використовує GPIO10, оскільки SX1509 pin 0 — рядок клавіатурної матриці.
- `src/gui.h` — основна точка входу для підключення GUI.
- Проект збирається через PlatformIO: `pio run`.

## English summary
The device is built as a modular embedded system with GUI, radio, sensor, GPS, sound, Wi‑Fi, and BLE modules. The UI is split under `src/GUI/`, and the hardware stack includes an ESP32-S3, ST7735 TFT display, SX1509 button expander, 4x4 keypad, GY-91 IMU, Si4735 radio, GPS module, and buzzer. Key I2C devices are SX1509 at 0x3E, MPU9250 at 0x68, BMP280 at 0x76, and AK8963 at 0x0C; the Si4735 address is detected dynamically. The keypad uses SX1509 columns 0-3 and rows 4-7; `c` is down and `d` is up; radio reset uses GPIO10.
